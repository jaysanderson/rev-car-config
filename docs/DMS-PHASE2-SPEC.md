## 3. API contract (all under /dms/api, bearer auth, same list conventions)

Service and job cards (cap `service.read` / `service.write`; gm, sales_manager, service_advisor and technician roles; two new demo logins `service@harbourline.demo` (service manager, role `service_manager`) and `tech1@harbourline.demo` (technician)):

| Method, path | Body / query | Returns |
|---|---|---|
| GET `/job-cards` | list params + `status`, `siteId`, `technicianId`, `advisorId`, `open=1`, `vin`, `rego` | `{items, total, page, pageSize}`; items carry `memoCount`, `imageCount`, `documentCount`, `daysOpen` |
| GET `/job-cards/board` | `siteId` | `{columns:[{status, cards:[...]}]}` for the workshop board |
| GET `/job-cards/:id` | | card + `customer`, `advisor`, `technician`, `memos[]`, `documents[]` (with `hasFile`, thumbnails for images), `vehicleHistory` (earlier cards for the VIN), `kbResourceId` |
| POST `/job-cards` | `{customerId, vehicle, advisorId, promisedAt, customerRequests[], loanCar, waiting}` | 201 card |
| PATCH `/job-cards/:id` | `{status?, technicianId?, promisedAt?, findings?, lines?}` | card; status change appends to history |
| POST `/job-cards/:id/lines` | `{type, code, desc, qty, hours, unitPrice, source, menuId}` or `{menuId}` (expands an Infomedia menu into lines) | card |
| POST `/job-cards/:id/memos` | `{kind, text, pinned}` | memo; the card's KB resource is re-synced (debounced) |
| POST `/job-cards/:id/documents` | same body as `POST /documents` (base64; images allowed) | document row linked to the card; images get a thumbnail |
| POST `/job-cards/:id/ask` | `{question, lang}` | `{answer, citations[], trace[], memosUsed:n}`; resource-scoped to this card plus service policies |
| POST `/job-cards/ask` | `{question, lang, filters?:{siteId,status,from,to}}` | `{answer, citations[], trace[], cardsConsidered:n, evidence:[{id, why}]}`; retrieval over `topic/jobcard` plus a structured summary of the filtered cards as extra context (counts, open cards, awaiting parts, overdue promises) |
| POST `/job-cards/:id/summary` | `{lang}` | agent-written handover note for the customer (what was done, what was found, what is next) with citations |
| POST `/job-cards/:id/sync-kb` | | re-upserts the resource (text + files) |

## 6. The Infomedia data pack, as we understand it

Infomedia (Sydney, ASX-listed until the December 2025 take-private) sells aftersales data to automakers and dealers: **Microcat EPC** (the electronic parts catalogue: part numbers, descriptions, supersessions, illustrations, prices, fitment by VIN) and **Superservice Menus** (VIN-specific service and repair menus built from OEM data: operations per interval, labour times, parts, menu prices, service-plan pricing), plus Superservice Connect (online booking), Triage (digital inspection) and Infodrive (data as a service). Dealers connect these to their DMS through the **DMSi** integration module: parts orders, prices and service menus are transferred into the DMS, and the DMS supplies customer and vehicle context; over 100 DMS providers integrate, and an Order API exists for web services. In dealer language, the "data pack" is the OEM-sourced bundle a dealer licenses: the parts price file, the labour times and menus for each model and interval, and the campaign and recall data, refreshed on a schedule.

Sources opened: [Superservice Menus](https://www.infomedia.com.au/products/service/superservice-menus/), [Microcat EPC](https://www.infomedia.com.au/products/parts/microcat-epc/), [DMSi v8 Integration Guide (Ford Europe, 2021)](https://www.infomedia.com.au/files/training/DMSi-v8-Integration-Guide-FEU-EN.pdf), [Infomedia company page](https://www.linkedin.com/company/infomedia-ltd), [DealerRefresh vendor profile](https://forum.dealerrefresh.com/vendors/infomedia/). Infomedia does not publish its file formats; the simulated pack is our own shape and is labelled as such.

What we build over it: the pack as knowledge-box resources with model labels, so the agent can answer "what does a 60,000 km service include on a 2022 RAV4 hybrid and what does it cost here" with citations; a deterministic quote function (menu plus the site's labour rate plus GST) with agent-written customer copy; campaign and recall awareness on job cards and in the owner surface; parts lookup in the job card line editor.
