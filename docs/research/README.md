# Research: world-class car buying experiences (16 Oct 2026)

Four parallel tracks, each a dated report with every URL opened:

- `track-oem-direct.md` — manufacturers selling direct or near-direct (Tesla, Rivian, Polestar, Ford, Toyota SmartPath and the Toyota AU dealer platform, Hyundai/Genesis, BMW, Mercedes-Benz)
- `track-online-retail.md` — online used-car retailers (Carvana, CarMax, Vroom, Shift, Cazoo, Cinch, Motorpoint, Amazon Autos, carsales retail, Carma, Cars24 AU, easyauto123, Pickles)
- `track-marketplaces-dealers.md` — marketplaces, dealer groups and dealer digital-retailing platforms, plus the industry research table (Cox, J.D. Power, YouGov, Deloitte)
- `track-emerging.md` — AI assistants, 3D/AR, instant finance and trade-in, buying and delivery, ownership apps, regulation; 15 beyond-the-bar candidates
- `harbourline-baseline.md` — the prototype as deployed, used for the parity matrix
