# Harbourline baseline (as deployed 16 Oct 2026) — for the parity matrix

Discover: model list with live stock counts per model/grade/colour (Domo stand-in); "For you" rows from semantic /find; offers strip (Domo targets + agent-composed promotions); multilingual assistant (EN/中文/Tiếng Việt).
Choose: five-question dynamic finder (JSON from the agent, branches on every answer), ranked top-3 with fit %, reasons, caveats, availability; nudges from Domo signals with stated reasons.
Configure: model, grade, colour, interior, Genuine accessories; photo per model (per-colour pipeline ready); real-time drive-away price (illustrative); SVG fallback.
Price: drive-away NSW estimate; ready-now bonus shown with reason; promotions as chips with customer-safe why; no fee breakdown screen; no payment calculator.
Finance and trade-in: knowledge-box answers on finance basics; no pre-qualification, no payment calculator, no trade-in valuation flow.
Reserve and buy: "Reserve this one" / hold 48 h / hold transfer / place order are toasts (no deposit, no e-sign); availability panel: on lot, nearby with transfer day, in transit, factory order with ETA.
Deliver: no delivery scheduling; test-drive booking with site/day/slot, three salesperson questions, show-up incentive, handover sheet to the DMS.
Own: nothing post-sale in the configurator; DMS has leads/test drives/deals.
Assistant: cited answers from spec sheets, pricing, warranty, finance, policy; mid-answer stock via Domo; build actions from answers; prefetch for finder speed.
Trust/transparency: data-layer toggle (reviewer), credits on photos, honesty rules for discounts.
Back office (DMS): leads with first-party configurator data, handover sheets, Domo signals, promotions provenance, report of configurator events, MCP + OpenAPI.
Gaps already known: official per-colour imagery, approved-offer vs headroom, phone layout untested, assistant ~5–8 s per answer, finder ~10 s per question (prefetched).
