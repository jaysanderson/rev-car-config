# Harbourline DMS seed data

Generated by `node scripts/dms-seed.mjs` (seed `harbourline-dms-v1`, deterministic) as of **2026-10-14T08:00:00+11:00**, with history from 2024-10-15. Re-run it to regenerate; `node scripts/dms-seed.mjs --check` prints a sanity report and integrity checks. All people, businesses, emails, phones, VINs and ABNs are synthetic.

Each table is a JSON array in `content/dms/data/<table>.json`. `_meta.json` holds counts and the Domo signal baseline used for calibration. Dataset descriptors for Domo are in `content/dms/domo-datasets.json`; derived datasets are computed by `server/dms/derive.mjs`.

## How the data behaves

- **Seasonality**: lead flow follows June EOFY and December peaks and a January dip (Christmas–New Year close-down), Saturday-heavy walk-ins, Sunday web/phone only, NSW public holidays closed, and about 7% growth a year. Deliveries are pulled forward into June (instant asset write-off) and before Christmas.
- **Funnel**: lead → contacted → qualified → test drive → quote (deal) → negotiation → finance (if financed through the dealer) → manager approval → contract → delivery → delivered. Probabilities depend on channel (walk-ins convert best, campaign leads worst, configurator bookings are high intent) and on the salesperson (close rate, discounting, response speed, F&I attach differ: e.g. Priya Natarajan and Jake Morrison convert ~40% of leads, Ben Whitfield and Aaron Fifita ~15%).
- **Fulfilment**: won deals are delivered from stock (2-7 days), from an allocated inbound unit (2-7 weeks) or by factory order (order-bank ETAs, longer for Prado and LandCruiser). From-stock deliveries in the last 90 days match `dealer_signals.sales90d` per model exactly, so days of supply agrees with Domo.
- **Stock**: the 22 configurator units are copied unchanged (HL-2231 94 days, HL-1941 110 days …). Historic units sold from stock (HL-1000..1899) carry their age at sale; aged units used their bonus headroom. `ordered` units equal Toyota's November allocation per model (Kluger 14).
- **Gross**: `frontGross = vehiclePrice − discount − bonus − landedCost + accessoriesGross − promotionCost − tradeOverAllowance`; `backGross` = finance commission (≈1.1–2.1% of amount) + insurance/warranty products, or small product income for cash deals; `grossProfit = frontGross + backGross`. `driveAway = vehiclePrice + onRoadCosts + accessoriesTotal − bonus − discount`. Typical front $1,000–$4,000, financed back $600–$2,800.
- **Demo scenarios**: open deals stuck in `finance` for more than 5 days at Penrith and Parramatta, deals waiting in `approval` for more than 3 days, `sales1@harbourline.demo` (Josh Pereira, started June 2026) with ~40 leads and ~25 deals, ~50 anonymous configurator bookings (`customerId` null, `customerRef` = session id), and the two document-processing contracts D-10482 (Priya Raman, HL-2231) and D-10517 (Daniel Okafor, HL-1941, GM-approved $2,900 concession) whose PDFs are DOC-1001..1006.

## Domo modelling guide

Load every table and derived dataset from `/dms/api/domo/export/<name>.csv` (catalogue at `/dms/api/domo/datasets`). Keep datetimes as DATETIME in Australia/Sydney. JSON columns arrive as strings: flatten them in Magic ETL (JSON Expand) only where needed; `deal_events` is already flat.

| dashboard card (spec §4) | datasets | how |
|---|---|---|
| Units vs target | `sales_daily` + `targets` | Sum `unitsDelivered` by `month`, `siteId`; join `targets` on (siteId, month). Attainment = units ÷ target. |
| Gross by site | `sales_daily` (or `deals` where stage = delivered) | Sum `frontGross`, `backGross`; GPU = gross ÷ `unitsDelivered`. Join `targets.grossTarget`. |
| Funnel | `funnel_weekly` | Sum steps by `week`/`channel`/`siteId`; plot leads → testDrivesCompleted → quoted → won. Use `leads` (duplicates excluded). |
| Stock ageing | `stock_ageing_daily` (trend) + `vehicles` (today) | Heat map of `avgDaysInStock` by site × model; bands from `units60Plus`, `units90Plus`. Today: vehicles where status in (on_lot, in_transit). |
| Days of supply | `dealer_signals` (+ `vehicles`, `deals`) | `daysOfSupply` (Domo) next to `erpDaysOfSupply`; inbound = `erpUnitsInbound`. |
| Leaderboard | `deals` + `staff` + `leads` | Group deals by `salespersonId`: delivered units, GPU, win rate; leads by `ownerId` for lead→delivery. |
| Configurator / DXM | `configurator_events` + `leads` + `test_drives` + `campaigns` | Sessions = distinct `sid`; bookings = type booking; join `sid` → `leads.configuratorSessionId` → `deals.leadId` for configurator-sourced sales. |
| Finance | `finance_apps` | Approval rate by `lender` = approved/conditional/settled ÷ decided; penetration = deals with financeAppId ÷ delivered. |
| Stage durations / stuck deals | `deal_events` or `deals.stageHistory` | Time between consecutive `stage_change` rows; open deals with `updatedAt` older than N days in a stage. |

Suggested beast modes (Domo SQL-style):

```sql
-- Gross per unit (sales_daily)
SUM(`grossProfit`) / NULLIF(SUM(`unitsDelivered`), 0)
-- Target attainment % (sales_daily joined to targets on siteId, month)
SUM(`unitsDelivered`) / NULLIF(MAX(`units`), 0)
-- Lead to delivery conversion (funnel_weekly)
SUM(`delivered`) / NULLIF(SUM(`leads`), 0)
-- Test-drive rate (funnel_weekly)
SUM(`testDrivesCompleted`) / NULLIF(SUM(`leads`), 0)
-- Close rate on test drives
SUM(`quoted`) / NULLIF(SUM(`testDrivesCompleted`), 0)
-- F&I penetration (sales_daily)
SUM(`financeDeals`) / NULLIF(SUM(`unitsDelivered`), 0)
-- Days of supply from vehicles + sales_daily (90-day window)
COUNT(CASE WHEN `status` IN ('on_lot','in_transit') THEN 1 END) / NULLIF(SUM(`unitsDeliveredFromStock`) / 90, 0)
-- Aged stock flag (vehicles)
CASE WHEN `daysInStock` > 90 THEN '90+' WHEN `daysInStock` > 60 THEN '61-90' WHEN `daysInStock` > 30 THEN '31-60' ELSE '0-30' END
-- Realised gross only (deals)
SUM(CASE WHEN `stage` = 'delivered' THEN `grossProfit` ELSE 0 END)
-- Discount + bonus as % of vehicle price (deals)
SUM(`discount` + `bonus`) / NULLIF(SUM(`vehiclePrice`), 0)
-- Days in current stage (deals, open)
DATEDIFF(CURRENT_DATE(), `updatedAt`)
```

Gotchas: count leads with `mergedIntoLeadId` empty; only `stage = delivered` gross is realised (`grossStatus`); `sales90d`/days of supply use from-stock deliveries (`fulfilment = stock`), not all deliveries; October 2026 is month-to-date; October 2024 starts on the 15th (its target is pro-rated).
